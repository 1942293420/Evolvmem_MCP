# 历史项目查找与数据范围说明

## 当前范围

历史页按当前获授权的用户读取历史项目与会话。原设备数据库选择器没有对应查询参数，不能实现 Windows/Linux 设备库切换；正式页用“当前读取所选用户历史库”和“设备库切换未接入”说明真实范围，不提供无效选择器。此变更不增加跨库读取权限。

项目目录来自历史迁移保留的项目归属和新会话上传时保存的项目归属。它不是电脑目录的实时扫描结果，历史归属也不等于全部重新核准。项目括号显示可见历史片段数，不是消息数或独立会话数；一个片段可能关联多个项目。

## 操作流程

用户选择已授权知识库 → 读取可见项目目录 → 打开项目选择框 → 输入部分名称或多个关键词 → 在本地过滤显示名及原项目键 → 选择结果 → 使用原项目键只读获取会话 → 阅读原文。

- 支持中文分散片段、多个关键词、英文大小写及全角输入；只在当前目录筛选，不做跨语言语义推断。
- 输入查找不会查询会话正文，也不修改归属、项目名、计数或回收站；选择结果后才加载对应项目。
- 无匹配时保留当前项目。清空只清关键词，不切换项目。
- 上下键和 Enter 选择，Escape 关闭；Tab 可以到达清空按钮，中文输入法确认不会误选。
- 每次选择使旧视图读取失效；慢响应不覆盖新项目，也不抢走后续输入焦点。切换用户库后清理旧查询和旧选项，重新显示可用授权库。

## 验证

`tests/browser/history_project_picker.e2e.cjs` 使用独立合成 HTTP 服务验证点击、键盘、输入法、全目录无预截断、慢请求、切库和手机布局，断言没有 POST。现有会话搜索和统一登录检查继续适用。
