# 开发能力浏览与查询性能

## 范围

本次调整面向 `/#knowledge/capabilities` 的检索、分页和来源追溯。能力记忆、待分类资料、分类建议继续使用原有存储与写入接口；不重跑生产历史，不迁移数据库，不添加未经测量支持的索引。

工作原理页新增“能力浏览”流程图，分为“筛选并追溯来源”和“确认待分类资料”两条路径。来源项目用于追溯；归入正式记忆不等于方法已有执行证据或验证成功。

## 查询接口

`GET /api/capabilities` 保留 `q`、`category`、`source_project`、`page` 和 `page_size` 参数。

- 正式记忆只查询 `status='active'`。先在 SQLite 计算匹配总数，再用 `LIMIT / OFFSET` 读取当前页；不再先读取并解码全部匹配正文，再由 Python 切片。
- 保持原有顺序：`updated_at DESC, memory_id DESC`。页大小夹取到 1–50，页码夹取到有效范围；无结果时仍返回第 1 页、共 1 页。
- `total` 对应全部生效筛选。分类 `counts` 继续只受关键词和来源项目影响，方便从当前分类切换到其他匹配分类。
- `source_projects` 返回全部有效记忆的非空来源项目，按来源字符串排序去重。它不受当前页、关键词、分类或已选来源影响，避免位于其他页的来源从下拉列表消失。
- `intake_total`、`suggestions_total` 分别统计所有 pending 资料与建议。待分类正文列表仍最多 200 条，页面不得把已加载数量当作全部待处理数量。分类建议列表保持原有完整返回语义。
- 保留 `filtered_capability_rows`，避免改变可能依赖完整结果的其他调用方。

这些改动减少传入 Python 的完整记忆行数及 JSON 解码量；SQL 计数与筛选仍可能扫描匹配范围。本次测试证明分页读取边界，没有据此声明生产响应时间或数据库扫描成本的固定降幅。

## 前端实现与验收约束

以下行为已由隔离浏览器回归确认；生产发布状态另见本地部署记录：

- 搜索框、分类、来源与分页应保留当前状态，切换页面返回后可继续浏览；未提交的搜索文字与待分类选择不应因无关操作丢失。
- 已读取结果优先复用。展开正文或来源只更新当前条目，不能重新获取列表或重建整个工作区。
- 页面提供明确的刷新操作。若设置缓存有效期或自动更新，应以最终代码和实际请求次数为准，避免一次浏览行为重复请求。
- 异步请求按当前筛选状态展示，较早返回的数据不得覆盖较新的选择。离开页面后不得把结果渲染到其他页面。
- 归类和处理建议只在用户点击确认后发起。保存成功后更新相应列表与计数；错误状态与重试入口可读，不能把列表刷新失败解释为保存失败。
- 来源选择直接使用接口的完整 `source_projects`，不从当前页拼凑，也不硬编码演示项目。
- 文案、正文、操作与空白状态采用正常可读字号；在桌面和窄屏核验边界、按钮与键盘操作。

## 合成验证

`tests/test_capability_web.py` 使用临时 SQLite，覆盖来源只存在于后续页、筛选为空时来源仍完整、205 条待分类资料的真实总数、已处理资料排除、页码与页大小边界、分类计数及状态筛选。

分页性能回归通过真实 SQLite 的行工厂记录完整记忆行的读取数量：9 条记忆中请求第 3 页、每页 2 条，只允许生成对应的 2 条完整记忆行。该验证不依赖计时阈值，也不使用生产数据。

`tests/browser/capability_archives_fixture.py` 提供临时资料库，用于搜索、分页、来源展开、待分类确认和分类建议的浏览器操作。存在写操作的验收必须指向合成服务，不应直接在生产资料中新增演示记忆或接受真实分类建议。

`tests/browser/product_modules.e2e.cjs` 使用单独的 `knowledge_fixture.py` 服务，读取 `EVOLVMEM_TEST_URL`、`PLAYWRIGHT_MODULE`、`CHROMIUM_EXECUTABLE` 环境变量。它不会自行启动服务，默认测试地址为 `http://127.0.0.1:39478`。新“能力浏览”图还需要检查节点、两条演示路径及不同屏宽。

## 部署与验证边界

通过现有用户级 `evolvmem-web.service` 管理方式部署。静态资源按请求读取；Python 查询模型更新需要重启 Web 服务。发布前保留相关文件备份与校验值，只替换本次文件，不覆盖其他未提交改动，不变更 MCP、自动整理或登录配置。

回归脚本 `tests/browser/capabilities_polish.e2e.cjs` 验证卡片局部更新、搜索草稿、跨页缓存、分页筛选、异步竞态、读取失败、加载中输入、离开时读取、五种屏宽及能力浏览流程图。`capabilities_guards.e2e.cjs` 拦截写入验证重复提交锁、实时只读权限、待分类选择、键盘与可见页签懒渲染。使用 TEST_BASE 指向全新合成服务，BROWSER_CHANNEL 可指定本地浏览器。

现有 product_modules 浏览器回归通过，浏览器未报告脚本异常。Python 相关回归的旧导航文案断言在原生产代码中也失败，属于既有问题；其余相关用例通过。生产登录页面和部署文件可通过服务与校验值核验，不能将合成数据中的浏览器测试视为已登录生产数据的完整验收。

缓存位于当前页面内存，最多12个查询、约4MiB；离开并返回保留已读结果，通过刷新按钮获取外部变化。写入成功后清除查询缓存。缓存不写入浏览器持久存储，退出登录会重新加载页面。
