# 首页读取优化与导航预览

## 首屏数据

Signal 首页独立读取能力概览与自动处理设置，各自返回即显示。不再请求默认隐藏的当前任务明细，效果统计在用户展开“效果与抽检”后加载。15秒内返回首页复用内存快照；周期更新和手动刷新保留旧结果。网络失败明确标记，不把缺失值当零。必要读取设10秒超时，效果统计设20秒超时，同类请求合并以避免重叠。

其他设计模板保留原有汇总展示。所有查询沿用登录鉴权，无新增后台写操作；不缓存到持久存储。

## 两版可操作导航

在根页面添加 `?nav-design=contrast#home` 使用 A 深蓝撞色，或 `?nav-design=cards#home` 使用 B 白色卡片。未带参数时保留原导航；用户选择后再将所选方案设为默认。

两个方案共用真实页面，11个既有入口全部展开为三组：日常工作、整理与维护、历史与说明。每个入口具有独立线性图标、当前页高亮、悬停位移和图标动效；键盘焦点可见，遵循减少动态效果设置。两版均采用横向顶部导航，页面滚动时冻结。宽屏三组并排，窄屏自动分行；短屏限制顶栏高度并允许顶栏内部滚动，保持所有入口可达。内容占满宽度，锚点和能力分类栏根据顶栏实际高度留出空间。

顶部方案切换直接改变样式并更新URL，保留当前查询和页面内容。返回原导航会重新打开默认页面。

## 验收

`tests/browser/home_speed.e2e.cjs` 使用独立合成服务验证：慢统计不阻塞首屏、无隐藏队列读取、返回复用、展开加载、手动刷新、错误保留、设置慢返回时仍显示卡片。

`tests/browser/nav_previews.e2e.cjs` 检查两方案的11个导航、3个分类、390/768/901/960/961/1024/1280/1366/1440/1560/1600/1920px，含390×500和844×390短屏、悬停动画、减少动态效果、原导航兼容与方案切换，并验证滚动后顶栏固定、分类栏不被遮挡、短屏入口可达。截图为合成数据预览，不代表生产记录。
