# 首页读取优化与导航预览

## 首屏数据

Signal 首页独立读取能力概览与自动处理设置，各自返回即显示。不再请求默认隐藏的当前任务明细，效果统计在用户展开“效果与抽检”后加载。15秒内返回首页复用内存快照；周期更新和手动刷新保留旧结果。网络失败明确标记，不把缺失值当零。必要读取设10秒超时，效果统计设20秒超时，同类请求合并以避免重叠。

其他设计模板保留原有汇总展示。所有查询沿用登录鉴权，无新增后台写操作；不缓存到持久存储。

## 默认顶部导航

用户已选择 A 深蓝撞色为默认，无需URL参数。旧的contrast/cards参数链接仍可打开相应样式。已移除方案切换与预览说明，保留正常页面URL和查询条件。

两个方案共用真实页面，11个既有入口全部展开为三组：日常工作、整理与维护、历史与说明。每个入口具有独立线性图标、当前页高亮、悬停位移和图标动效；键盘焦点可见，遵循减少动态效果设置。两版均采用横向顶部导航，页面滚动时冻结。按用户确认的 SVG 第02版：桌面采用约112px双排顶栏，每组两列、两行，品牌与账号位于左右窄栏。Logo仅保留40px图标；导航图形24px、底板32px、文字14px、点击区域44px高。分组用竖线与图标颜色区分，保留分类的读屏及悬停名称。窄屏继续分组换行，保持图标及文字尺寸。账号头像可展开姓名及权限，退出按钮仍使用原有CSRF与登录状态处理。，窄屏自动分行；短屏限制顶栏高度并允许顶栏内部滚动，保持所有入口可达。内容占满宽度，锚点和能力分类栏根据顶栏实际高度留出空间。

导航点击继续沿用现有路由，保留查询和页面内容。

## 能力页下拉选择

能力页的来源项目筛选和待分类选择使用统一菜单：独立标签、圆角面板、选中标记、悬停与键盘焦点。归类标签位于控件上方，控件与确认按钮底部对齐，避免文字重叠。

真实select保留原有值和change事件，组合框提供鼠标、方向键、Home/End、Enter/空格、Escape和Tab操作；原生控件退出Tab顺序，避免重复焦点。禁用状态与现有权限/请求状态同步。菜单随切页、失焦或页面滚动关闭，不影响缓存草稿；浮层限高并适配视口边缘。仅增强能力页现有两类选择，不改其他业务页面。

## 验收

`tests/browser/home_speed.e2e.cjs` 使用独立合成服务验证：慢统计不阻塞首屏、无隐藏队列读取、返回复用、展开加载、手动刷新、错误保留、设置慢返回时仍显示卡片。

`tests/browser/nav_previews.e2e.cjs` 检查两方案的11个导航、3个分类、390/768/901/960/961/1024/1280/1366/1440/1560/1600/1920px，含390×500和844×390短屏、悬停动画、减少动态效果、默认A、旧参数链接兼容、桌面每组双排、约112px高度、24px图标、账户展开及退出失败反馈、导航无遮挡，并验证滚动后顶栏固定、分类栏不被遮挡、短屏入口可达。截图为合成数据预览，不代表生产记录。

`tests/browser/capability_select.e2e.cjs` 使用合成资料及拦截写请求验证选择交互、菜单关闭、禁用同步、跨页选择保留、标签间距、菜单位置与原有归类提交内容。
