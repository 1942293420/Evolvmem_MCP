# 正式控制台的数据来源与未完成能力

正式 HTTP/HTTPS 页面只显示已成功读取的数据。初次连接显示加载状态，失败显示明确错误与重试入口；不以离线示例记录、固定指标或零值代替未知结果。file:// 预览保持独立并明确标为离线演示。

## 页面与工作流程

主界面工作流程：客户端原文采集上传 → 原文归档 → 分轨候选提炼及门禁 → 人工审阅 → 正式经验 → 按需检索。流程图说明模块关系，不表示客户端、数据库或调度器当前健康。

- 总览使用当前库的真实有效经验、双轨待审数量和最近经验变更。
- 流水线使用实际熔断状态、最近片段运行、模型调用汇总、回填游标和清洗登记。历史累计与限量列表不冒充今日预算或全量覆盖。
- 历史页保留项目、会话及原文读取；缺客户端回执时不显示“零积压”等固定状态。
- 进化指标、晋升、休眠、习惯、手册发布及即时推坑尚未形成后台闭环，显示待开发，禁止在浏览器内模拟成功。
- Skill 目录保留真实同步的条目。目录存在不等于已安装、自动结晶成功或评测通过；未知 Token、分发状态与效果不推算为实测值。
- 溯源缺少相似度、阈值、试用计数或裁判模型时显示未返回，保留真实零值。诊断不显示预置在线、备份恢复或句柄结论。

## 异常、权限与异步请求

切库先清理已读取的数据，并递增库版本。旧请求和旧历史读取链不得写回新视角；抽屉切换、关闭和库变更后，旧成功或失败回调不得覆盖新内容。未接通的动作即使直接调用也不能修改状态或报告成功。真实写操作仍沿用现有后台鉴权、CSRF 和业务入口。

## 验证入口

- `node --test tests/browser/console_truth.test.cjs tests/browser/console_truth_details.test.cjs`：正式与离线状态、接口失败、零值和空目录、权限、切库与抽屉竞态、缺失指标。
- `tests/browser/console_truth.e2e.cjs`：独立 HTTP fixture，主页面、待开发按钮、手机宽度、错误重试，断言没有 POST。使用已有 Playwright 与 Chromium，可通过环境变量指定位置。
- `tests/stage5/test_web_console_v2_full_chain.py`：隔离 PostgreSQL 验证真实 HTTP/API/鉴权/审阅/救回等现有功能。

本次不改变经验检索算法、模型、数据迁移、提炼开关或统一登录规则。
